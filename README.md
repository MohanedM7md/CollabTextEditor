# Realtime Collaborative Text Editor

A real-time collaborative plain text editor built as a college project using **Spring Boot** and **JavaFX**. It allows multiple users to edit the same document simultaneously with features like live updates, user roles, and conflict-free changes.

## Features
- Real-time collaborative editing
- User roles: editor/viewer
- Undo/redo support
- Inline comments and highlights
- Built with CRDT (Conflict-free Replicated Data Types)

## Tech Stack
- **Backend**: Spring Boot (WebSocket, REST APIs)
- **Frontend**: JavaFX

## How to Run
1. Start the Spring Boot server.
2. Run the JavaFX client.
3. Open multiple clients to test collaboration.
